# Портфолио: Кафедра компьютерного дизайна

Учебный проект для практических работ №3 и №4 (РТУ МИРЭА). 
Выполнил: Фирстов Максим.

## Технологии
* HTML5 (семантическая разметка)
* CSS3 (Flexbox, Grid, адаптивная верстка)
* JavaScript (интерактивные компоненты: табы, аккордеон, модальное окно, слайдер, валидация формы)
