# Портфолио: Кафедра компьютерного дизайна

Учебный проект для практических работ №3 и №4 (РТУ МИРЭА). 
Выполнил: Фирстов Максим.

## Описание проекта
Интерактивное онлайн-пространство для просмотра работ студентов кафедры компьютерного дизайна. Разработано по дизайн-макету с соблюдением принципов доступности, адаптивности и UX/UI паттернов.

## Реализованные интерактивные компоненты
* **Мобильное меню** (с плавным появлением)
* **Табы (вкладки)** для фильтрации работ по курсам
* **Аккордеон** (FAQ) с открытием только одного пункта
* **Слайдер** новостей с кнопками управления и счетчиком слайдов
* **Модальное окно** с формой обратной связи, проверкой полей (email, заполненность, согласие) и размытием фона
* **Уведомление о cookies**

## Технологии
* HTML5 (семантическая разметка)
* CSS3 (Flexbox, Grid, адаптивная верстка, CSS-анимации `keyframes` и `transition`)
* JavaScript (ES6+, DOM API, Event Listeners)
